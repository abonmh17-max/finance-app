# تطبيق تنظيم النفقات المالية — بناء APK عبر GitHub Actions

## الفكرة باختصار
نعم، صح. إذا رفعت هذا الكود إلى GitHub، سيقوم GitHub Actions ببناء ملف APK
في سحابته هو، بدون الحظر الموجود عندي، وستنزّل ملف APK الجاهز من صفحة الـ Actions.

## الملفات في هذا المشروع
- `assets/www/index.html` — التطبيق نفسه (أوفلاين، التاريخ، الملاحظات، الصوت، Excel)
- `src/com/muse/finance/MainActivity.java` — كود أندرويد (WebView + جسر التنزيل + جسر الصوت)
- `AndroidManifest.xml` — الحزمة `com.muse.finance`، الإصدار 1.0.1، أندرويد 5 فما فوق
- `res/` — الواجهة والأيقونة
- `build-apk.sh` — سكربت البناء بدون Gradle
- `.github/workflows/build-apk.yml` — ملف GitHub Actions الذي يبني APK تلقائياً

## الخطوات
1. أنشئ حساباً على https://github.com إذا لم يكن عندك، ثم أنشئ مستودعاً جديداً (Repository) باسم مثلاً `finance-app`، واجعله Private (خاص) إذا أردت.
2. ارفع كل ملفات هذا المجلد إلى المستودع (زر Add file ثم Upload files، أو عبر git).
3. بعد الرفع، اذهب إلى تبويب **Actions** في المستودع، وستجد تشغيلاً باسم **Build APK** يعمل تلقائياً.
4. انتظر حتى تظهر علامة صح خضراء (تستغرق عادة 2-4 دقائق).
5. اضغط على التشغيل، وانزل إلى الأسفل إلى قسم **Artifacts**، ونزّل `finance-app-v2`.
6. فك ضغط الملف المنزّل، وستجد بداخله `finance-app.apk` (341K تقريباً)، وثبّته على هاتفك.

## ملاحظات
- APK الناتج موقّع بمفتاح تصحيح (debug) يُنشأ أثناء البناء، وليس توقيع متجر Play.
- إذا عدّلت التطبيق لاحقاً، ارفع التعديل إلى GitHub وسيُبنى APK جديد تلقائياً.
- إذا فشل البناء، افتح سجل التشغيل في Actions وانسخ رسالة الخطأ.
